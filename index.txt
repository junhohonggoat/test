1. 서비스 기획 및 작동 구조
--------------------------------------------------------------------------------
■ 사장님 (어드민) 화면:
  - 구글 계정으로 안전하게 로그인 (사전에 등록된 관리자만 접속 허용)
  - 달력에서 날짜를 누르고 당일 메뉴(A~F 슬롯) 직접 등록/수정/휴무 설정
  - 해당 날짜에 들어온 손님들의 예약 현황(테이크아웃 시간, 배달 주소, 연락처) 확인

■ 손님 (일반 고객) 화면:
  - 스마트폰으로 접속하여 달력에서 날짜를 누르고 당일 식단 확인
  - 수령 방식 선택:
    1) [테이크아웃] -> 픽업 희망 시간 + 예약자명 + 연락처 입력 -> 예약 완료
    2) [배달] -> 배달 주소 + 상세 주소/공동현관 비번 + 연락처 입력 -> 주문 완료

■ 개인정보 보호 원칙:
  - 손님의 이름, 연락처, 집 주소, 공동현관 비밀번호는 민감한 개인정보입니다.
  - 보안 규칙을 통해 '일반 손님은 주문 등록만 가능'하고, '남의 주문서 및 개인정보는 오직 사장님만 열람'할 수 있도록 철저히 차단합니다.

2. 1단계: 파이어베이스 새 프로젝트 생성
--------------------------------------------------------------------------------
1) 구글 크롬 브라우저에서 파이어베이스 콘솔(https://console.firebase.google.com/) 접속
2) [프로젝트 만들기] 버튼 클릭
3) 프로젝트 이름 입력 (예: mamgadeukchan-live)
4) Google 애널리틱스는 사용 안 함 또는 기본값 유지 후 [프로젝트 만들기] 완료

--------------------------------------------------------------------------------
3. 2단계: 핵심 기능 3가지 활성화 (콘솔 작업)
--------------------------------------------------------------------------------
① Authentication (로그인 기능):
   - 좌측 메뉴 [빌드] -> [Authentication] 클릭
   - [시작하기] 클릭 후 'Sign-in method' 탭에서 [Google] 선택 -> [사용 설정] 토글 켜기
   - 프로젝트 지원 이메일 선택 후 [저장]

② Cloud Firestore (데이터베이스):
   - 좌측 메뉴 [빌드] -> [Firestore Database] 클릭
   - [데이터베이스 만들기] 클릭
   - 데이터베이스 위치: 'asia-northeast3 (서울)' 선택 (매우 중요: 속도 빠름)
   - 보안 규칙은 우선 기본값(프로덕션 모드)으로 완료

③ 웹 앱 등록 및 설정값 확인:
   - 프로젝트 홈 화면(프로젝트 개요 옆 톱니바퀴 -> 프로젝트 설정) 이동
   - 화면 하단 '내 앱' 섹션에서 [</>] (웹 아이콘) 클릭
   - 앱 닉네임 입력 (예: 맘가득찬웹) 후 [앱 등록]
   - 화면에 표시되는 `firebaseConfig` 코드(apiKey, projectId 등) 확인

--------------------------------------------------------------------------------
4. 3단계: 개인정보 보호 & 보안 규칙(Security Rules) 설정
--------------------------------------------------------------------------------
Firestore 콘솔 -> [규칙(Rules)] 탭으로 이동하여 기존 내용을 지우고 아래 규칙을 붙여넣고 [게시]:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    
    // 관리자 판별 함수: admins 컬렉션에 해당 이메일이 등록되어 있는지 검사
    function isAdmin() {
      return request.auth != null && exists(/databases/$(database)/documents/admins/$(request.auth.token.email));
    }

    // 1. 관리자 명단: 관리자 본인만 확인 가능
    match /admins/{email} {
      allow read: if request.auth != null && request.auth.token.email == email;
      allow write: if false; 
    }

    // 2. 메뉴판: 누구나 읽을 수 있음, 등록/수정은 오직 관리자만!
    match /menus/{date} {
      allow read: if true;
      allow write: if isAdmin();
    }

    // 3. 손님 주문서 (개인정보 보호 핵심):
    // - 주문 넣기(create)는 누구나 가능
    // - 주문 조회(read), 수정, 삭제는 오직 '관리자(사장님)'만 가능!
    match /orders/{orderId} {
      allow create: if true;
      allow read, update, delete: if isAdmin();
    }
  }
}

--------------------------------------------------------------------------------
5. 4단계: 관리자(사장님) 계정 등록
--------------------------------------------------------------------------------
Firestore 콘솔 -> [데이터(Data)] 탭 이동:
1) [+ 컬렉션 시작] 클릭
2) 컬렉션 ID: `admins` 입력 후 [다음]
3) 문서 ID에 사장님의 구글 이메일 주소 직접 입력 (예: mailinnence@gmail.com)
4) 필드에 `role: "admin"` 하나 넣고 [저장]
-> 이제 사장님 구글 계정으로 로그인하면 관리자 권한이 정상 부여됩니다.

--------------------------------------------------------------------------------
6. 5단계: 웹 소스코드 구성 (손님용 + 사장님용)
--------------------------------------------------------------------------------
폴더 구조:
public/
  ├── index.html        (일반 손님용: 달력 + 메뉴 확인 + 테이크아웃/배달 모달 예약창)
  └── admin/
      └── index.html    (사장님용: 구글 로그인 + 메뉴 입력 + 일자별 예약자 명단 실시간 조회)
firebase.json           (호스팅 배포 경로 설정)
.firebaserc             (새로 만든 파이어베이스 프로젝트 ID 지정)

* 각 html 파일의 `firebaseConfig` 객체 안에 3단계에서 발급받은 새 프로젝트 키를 입력합니다.

--------------------------------------------------------------------------------
7. 6단계: 내 컴퓨터에서 배포(Deploy) 및 웹사이트 공개
--------------------------------------------------------------------------------
1) 터미널(PowerShell)에서 프로젝트 폴더로 이동:
   cd C:\Users\Donkey\Desktop\firebase

2) 새로 만든 프로젝트 ID 연결:
   .firebaserc 파일의 "default" 값을 새 프로젝트 ID로 변경

3) 배포 명령어 실행:
   firebase deploy --only hosting

4) 10초 후 배포 완료 메시지와 함께 평생 무료 보안 웹사이트 주소 발급:
   - 손님용: https://[새프로젝트ID].web.app
   - 사장님용: https://[새프로젝트ID].web.app/admin/
