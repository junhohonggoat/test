카카오톡 채널에 Python 자동 응답 프로그램 연결하기

응답 프로그램은 Python으로만 만들 수 있습니다.
목표: 사용자가 채널에 1을 보내면 2라고 답하기.

1. 챗봇을 만들고 채널을 연결하세요

카카오 챗봇 관리자센터에 접속합니다.
https://i.kakao.com/

1) 채널을 만든 계정으로 로그인합니다.
2) 봇 만들기 → 카카오톡 챗봇을 선택합니다.
3) 봇 이름을 입력합니다. 예: 파이썬 테스트
4) 설정 → 카카오톡 채널 연결에서 방금 만든 채널을 연결합니다.

채널이 목록에 없으면 해당 계정의 채널 관리 권한과 기존 챗봇 연결 여부를 확인해야 합니다.
공식 연결 안내:
https://kakaobusiness.gitbook.io/main/tool/chatbot/tutorial/make_chatbot/tutorial_1

2. Python 응답 프로그램을 준비합니다

사용할 라이브러리는 Flask입니다. 카카오 전용 라이브러리는 필요하지 않습니다.

설치:
python -m pip install flask

다음 코드를 app.py로 저장합니다.

from flask import Flask, request, jsonify

app = Flask(__name__)


@app.post("/kakao/skill")
def reply():
    data = request.get_json(silent=True) or {}
    message = data.get("userRequest", {}).get("utterance", "").strip()

    answer = "2" if message == "1" else "1을 보내주세요."

    return jsonify({
        "version": "2.0",
        "template": {
            "outputs": [
                {"simpleText": {"text": answer}}
            ]
        }
    })


if __name__ == "__main__":
    app.run(host="127.0.0.1", port=3000, debug=False)

실행:
python app.py

이제 PC에서 카카오 요청을 받을 프로그램이 실행됩니다.
요청과 답변은 카카오가 정한 JSON 형식을 사용합니다.
공식 규격:
https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/answer_json_format

3. PC에 외부 접속 주소를 연결합니다

카카오 서버는 내 PC의 localhost에 직접 접속할 수 없습니다.
그래서 테스트용 HTTPS 터널을 연결해야 합니다.

응답 코드는 전부 Python이고, 터널은 외부 접속 주소를 붙여주는 보조 도구입니다.
예를 들어 cloudflared 설치 후 별도 터미널에서 실행합니다.

cloudflared tunnel --url http://localhost:3000

출력된 주소가 다음과 같다면:
https://example.trycloudflare.com

등록할 스킬 주소는 다음과 같습니다.
https://example.trycloudflare.com/kakao/skill

이 임시 주소는 터널을 다시 실행하면 바뀝니다.
공식 터널 안내:
https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/

4. 카카오에서 Python 프로그램을 연결합니다

챗봇 관리자센터에서 설정합니다.

1) 스킬 → 생성으로 이동합니다.
2) 스킬 이름을 정하고, 위 HTTPS 스킬 주소를 URL에 넣어 저장합니다.
3) 시나리오에서 새 블록을 만듭니다.
4) 사용자 발화에 1을 등록합니다.
5) 블록에 만든 스킬을 연결합니다.
6) 봇 응답을 스킬데이터 사용으로 설정하고 저장합니다.

공식 스킬 설정 안내:
https://kakaobusiness.gitbook.io/main/tool/chatbot/skill_guide/make_skill
